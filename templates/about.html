The Five Capstone Modules

MODULE 1

Student Query Processing

Responsible for input ingestion, data hygiene, linguistic normalization, and intent classification.

  • Input Validation: Prevents empty or malformed strings with actionable student prompts.
  • Text Normalization: Strips noise, converts character encodings, and extracts informative domain keywords.
  • Query Classification: Accurately routes questions into 7 categories (Attendance, Examination, Fees, Academic, Course Information, Admission, General).
MODULE 2

AI Agent-Based Query Resolution

The central autonomous intelligence coordinator named University Query Agent.

  • Decision Engine: Analyzes query taxonomy and decides whether knowledge base retrieval or direct answering is optimal.
  • Transparent Cognitive Steps: Exposes a 7-stage live telemetry trail (Received → Cleaned → Classified → Decided → Searched → Generated → Ready).
  • Audit Logging: Automatically stores all resolution telemetry, latencies, and match scores in SQLite.
MODULE 3

Academic Document Retrieval

Semantic vector search pipeline executing Retrieval-Augmented Generation (RAG).

  • Document Chunking: Partitions raw policy files into semantic paragraph chunks with sliding overlap.
  • Vector Similarity: Converts chunks into high-dimensional TF-IDF vectors and computes Cosine Similarities against incoming student queries.
  • Relevance Scoring: Returns calibrated similarity percentages (e.g. 92%) and pinpoint context chunks.
MODULE 4

Knowledge Base Management

Dynamic document catalog and ingestion management system.

  • Verified Academic Sources: Houses official attendance rules, exam guidelines, academic calendar, fee schedules, courses, and admissions.
  • Dynamic Ingestion: Administrators can add new documents via web form, instantly saving and vector-indexing them.
  • Index Refresh: Re-indexes files at runtime without requiring server restarts.
MODULE 5

User Interface and Response Delivery

Modern SaaS-styled light interface delivering transparent module-by-module results.

  • Modern Light Aesthetic: Bright, clean, and accessible UI with subtle shadows, crisp cards, and indigo accents.
  • Live Agent Animation: Visualizes the step-by-step reasoning cycle during query resolution.
  • Module Breakdown Cards: Clearly renders category, retrieved file, relevance score, context snippet, and the final response.
